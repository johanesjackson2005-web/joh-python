# JMJ WebView App

This folder contains a simple Android WebView app that opens your Django website inside an app shell.

## Build steps
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build Bundle(s)/APK(s) > Build APK.
4. Install the generated APK on your Android phone.
